# Awesome Android Root

A curated index of Android root apps and modules, with practical rooting guides, tutorials and troubleshooting references.

[Website](https://awesome-android-root.xyz) · [Contribute](CONTRIBUTING.md) · [GitHub](https://github.com/awesome-android-root/awesome-android-root)

## About the project

The collection is maintained as plain Markdown under [`docs/`](docs/). App and module entries are grouped by use case and include project links, licensing information and framework compatibility where known.

- **Rooting guides:** Magisk, KernelSU, APatch, LSPosed, bootloader unlocking and device-specific walkthroughs.
- **Apps and modules:** tools for root management, privacy, system configuration, backup, networking and other tasks.
- **Tutorials and help:** ad blocking, debloating, FAQs, troubleshooting and non-root alternatives.

Rooting and system modifications can erase data, affect warranty or device security, and prevent some apps from working. Make a verified backup and check the device-specific requirements before proceeding. See the [legal disclaimer](https://awesome-android-root.xyz/legal-disclaimer).
