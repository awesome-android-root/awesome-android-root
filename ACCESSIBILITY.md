# Accessibility

This page covers accessibility for the Awesome Android Root website ([awesome-android-root.xyz](https://awesome-android-root.xyz)) and the Markdown documentation in this repository.

## Site features

- Keyboard navigation, a skip-to-content link, and `:focus-visible` outlines on interactive controls.
- Light and dark themes via the header appearance switch, plus `prefers-reduced-motion` and `prefers-contrast` styles.
- Accessible labels on custom controls, store badges, local search, and polite live-region status updates.
- Plain-text access: pages can be copied or downloaded as Markdown, or read directly under [`docs/`](docs/) on GitHub.

## Contributing

- Keep headings in order, write descriptive link text, and add `alt` text to meaningful images.
- Keep UI controls keyboard-operable with visible focus styles, accessible names, readable contrast, and reduced-motion support.
- Follow [`CONTRIBUTING.md`](CONTRIBUTING.md) when submitting changes.

## Reporting an issue

To report an accessibility barrier on the site or in the documentation, [open a GitHub issue](https://github.com/awesome-android-root/awesome-android-root/issues/new?template=bug-report.md) with the page URL or file path and what happened. Browser, assistive technology, and screenshot details are optional.
