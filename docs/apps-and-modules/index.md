Framework labels are informational. Check the linked project for device, Android-version and root-method requirements before installing.

## Safety checklist

::: warning Before making system changes
- Make and verify a backup of important data.
- Confirm that the package supports your device and Android version.
- Keep the original boot and firmware images available for recovery.
- Understand that unlocking a bootloader usually erases user data and may affect warranty, device security or app compatibility.

See the [legal disclaimer](/legal-disclaimer) and [rooting guides](/rooting-guides/) before proceeding.
:::
