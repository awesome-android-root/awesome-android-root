# Performance & Battery

**Performance & Battery** collects apps and modules that make a rooted Android faster and last longer:
CPU/GPU and general **performance optimization**, **kernel management**, **memory & RAM** tuning, **battery
optimization**, charging control and task & process management.

- **[BatStats](https://github.com/mlm-games/BatStats)** - Battery monitor with stats via Shizuku/root. `FOSS`
- **[Battery Info Enabler](https://github.com/klab7/BatteryInfoEnabler)** - Enlocks and enhances the native battery information for Pixel 6+ devices. `FOSS` `[LSP]`

- **[NoWakeLock](https://github.com/NoWakeLock/NoWakeLock)** - An application that controls Android wakelocks can run on Android N and later. `FOSS` `[LSP]`
