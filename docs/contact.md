# Contact Awesome Android Root

Awesome Android Root is a community-curated documentation project. The project does not provide device repair, manufacturer support, or private technical support for every device or third-party application listed here. For questions about a specific guide or listing, use the public project channels below and include the page URL and enough context to reproduce the issue.

## General questions and corrections

Open a [GitHub issue](https://github.com/awesome-android-root/awesome-android-root/issues/new) for questions about the website, suggested corrections, broken links, or missing documentation. Include the affected page, relevant Android version or device details when applicable, and the steps you followed. Do not include passwords, private keys, account credentials, or personal data in a public issue.

## Contributions

Documentation corrections and additions can be submitted as a [pull request](https://github.com/awesome-android-root/awesome-android-root/pulls). Please cite authoritative sources for compatibility, installation, security, and maintenance claims. Device-modification instructions should state the exact model and relevant software version, and should retain warnings about backups, data loss, boot failures, and recovery.

## Security reports

Do not publish security vulnerabilities in a public issue. Use the repository's [private security advisory form](https://github.com/awesome-android-root/awesome-android-root/security/advisories/new). The published [security policy](https://github.com/awesome-android-root/awesome-android-root/blob/main/SECURITY.md) explains the information that helps maintainers reproduce and assess a report. For general questions, use GitHub issues instead.

The project does not publish a postal address or guaranteed response time. GitHub is the maintained contact channel for this community project.
